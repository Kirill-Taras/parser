# 🥗 Парсер меню ресторана "С.."

Этот скрипт автоматически загружает меню ресторана, сохраняет структуру категорий и блюд в `menu.json`, а также скачивает изображения блюд в папку `images/`.

## 🚀 Возможности
- Получение данных меню через API сайта.
- Сохранение меню в удобном JSON-формате.
- Скачивание фотографий блюд.
- Подготовка данных для интеграции в Telegram-бот.

## 📂 Структура проекта
├── images/ # Скачанные картинки блюд
├── menu.json # Сформированный JSON с меню
├── parser.py # Основной скрипт парсера
├── .env # Переменные окружения (URL API)
└── requirements.txt # Зависимости проекта

## ⚙️ Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/username/parser.git
   cd parser
   ```
   
2. Установить зависимости:
    ```bash
    pip install -r requirements.txt
    ```

3. Создать файл .env и указать адрес API:
    ```bash
    MENU_URL=https://api.restoran.com/rest/enkod/init?_format=json
    ```

4. Запустить парсер:
    ```bash
    python parser.py
    ```
